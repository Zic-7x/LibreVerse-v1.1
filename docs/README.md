# Documentation

Project documentation lives here, separate from application source.

## Layout

| Path | Purpose |
|------|---------|
| `architecture/` | System design, C4 diagrams, layer boundaries |
| `api/` | OpenAPI specs, endpoint reference |
| `adr/` | Architecture Decision Records |
| `guides/` | Onboarding, runbooks, how-tos |
| `diagrams/` | Source files for architecture and sequence diagrams |

## ADR Template

Each ADR in `adr/` should capture: context, decision, consequences, and status.
